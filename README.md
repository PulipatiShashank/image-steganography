# 🖼️ Image Steganography Tool (JPEG + PNG)

This Python tool hides secret messages inside **JPEG or PNG images** using **Least Significant Bit (LSB)** steganography. It can also extract those messages later.

## ✅ Features
- Supports **both PNG and JPEG**
- Simple encryption (hiding text)
- Simple decryption (extracting text)
- No external libraries except Pillow
